# Образовательная платформа для курсов программирования

## 1. Общая идея

Создать образовательную платформу по типу Stepik, но ориентированную на собственные курсы по программированию и другим IT-направлениям.

На сайте существует два отдельных интерфейса:

1. **Сайт преподавателя**
2. **Сайт студента**

Оба сайта используют:

- единый Backend API;
- единую базу данных;
- единые аккаунты;
- единые курсы;
- единые данные о прогрессе.

Регистрации студентов на сайте нет.

Студенту аккаунт создаёт преподаватель.

---

# 2. Роли пользователей

## Преподаватель

Преподаватель может:

- создавать курсы;
- редактировать курсы;
- создавать блоки курса;
- создавать уроки;
- загружать уроки в формате `.md`;
- добавлять задания;
- создавать экзамены;
- создавать группы;
- создавать аккаунты студентов;
- выдавать студентам доступ к курсам;
- смотреть прогресс студентов;
- смотреть прогресс группы;
- редактировать данные студентов;
- блокировать/разблокировать студентов;
- сбрасывать прогресс;
- просматривать результаты экзаменов.

## Студент

Студент может:

- входить в свой аккаунт;
- смотреть доступные курсы;
- проходить уроки;
- выполнять задания;
- проходить экзамены;
- смотреть свой прогресс;
- смотреть свой профиль;
- менять имя;
- менять пароль;
- видеть свою группу;
- продолжать курс с последнего места.

# 3. Авторизация

## Регистрация

Публичной регистрации нет.

Студентов создаёт преподаватель.

### Быстрое создание студента

Преподаватель нажимает:

**"Создать студента"**

Минимально вводит:

- имя;
- фамилию;
- группу.

Система автоматически создаёт:

```text
Логин: student_4821
Пароль: A7k92Lm4
```

После создания показать:

```text
Студент создан

Логин: student_4821
Пароль: A7k92Lm4

[Скопировать данные]
```

Преподаватель может сразу отправить эти данные студенту.

Дополнительно должна быть кнопка:

**"Сгенерировать новый пароль"**

# 8. Уроки в формате Markdown

Основной контент уроков хранится в формате `.md`.

Пример:

```markdown
# Переменные в Python

## Что такое переменная

Переменная хранит значение.

Пример:

```python
name = "Magamed"
age = 20
```

## Что нужно запомнить

- переменная хранит данные;
- имя переменной должно быть понятным;
- значение можно изменить.

## Практика

Создай переменные:

- name
- age
- city

Выведи их через print().
```

Система должна:

1. хранить `.md`;
2. отображать Markdown как красивую HTML-страницу;
3. поддерживать:
   - заголовки;
   - списки;
   - таблицы;
   - код;
   - изображения;
   - ссылки;
   - цитаты;
   - выделение текста.

---

# 9. Типы уроков

Желательно предусмотреть несколько типов блоков:

### Теория

Markdown-урок.

### Практика

Задание, которое студент должен выполнить.

### Тест

Например:

```text
Как вывести текст в Python?

A) echo()
B) print()
C) text()
D) console()
```

### Домашнее задание

Студент отправляет ответ/файл.

### Экзамен

Отдельный контролируемый блок.

---

# 10. Последовательное прохождение курса

Это одна из основных функций платформы.

Студент **не может сразу открыть последний урок курса**.

Например:

```text
Урок 1 ✅
Урок 2 ✅
Урок 3 🔓
Урок 4 🔒
Урок 5 🔒
Урок 6 🔒
```

После завершения урока открывается следующий.

Правило:

```text
Текущий урок завершён
        ↓
Открыть следующий урок
```

Нельзя:

```text
Открыть урок 10
Открыть урок 20
Открыть экзамен
```

если предыдущие уроки не завершены.

# 11. Завершение урока

В конце урока должна быть кнопка:

**"Завершить урок"**

После нажатия:

```text
Урок завершён ✅

Следующий урок открыт.
```

В БД сохраняется:

```text
student
course
lesson
completed = true
completed_at
```

# 14. Экзамены

Экзамен должен быть закрыт до завершения соответствующего блока.

Например:

```text
Блок 1
✅ Урок 1
✅ Урок 2
✅ Урок 3
✅ Урок 4

🔓 Экзамен блока 1
```

До этого:

```text
🔒 Экзамен закрыт

Сначала завершите все уроки блока.
```

# 15. Экзамен

Преподаватель может создавать:

- название;
- описание;
- вопросы;
- варианты ответов;
- правильные ответы;
- проходной балл;
- количество попыток.

Например:

```text
Экзамен: Python Основы

10 вопросов
Проходной балл: 70%
Количество попыток: 3
```

После завершения:

```text
Результат: 8 / 10
80%

✅ Экзамен пройден
```

Если экзамен не пройден:

```text
❌ Экзамен не пройден

Попробуйте ещё раз.
```

```text

# 31. Главные правила системы

### Правило 1

Студент не может открыть незакрытый предыдущий урок.

### Правило 2

Следующий урок открывается после завершения предыдущего.

### Правило 3

Экзамен открывается только после завершения обязательных уроков блока.

### Правило 4

Курс доступен только студентам, которым преподаватель выдал доступ.

### Правило 5

Преподаватель может видеть прогресс своих студентов.

### Правило 6

Преподаватель может создавать и редактировать учебный контент.

### Правило 7

Студент не может изменять курс или его структуру.

### Правило 8

Студент не может зарегистрироваться самостоятельно.

# 35. Главная концепция проекта

```text
Преподаватель
      ↓
Создаёт студента
      ↓
Создаёт группу
      ↓
Создаёт курс
      ↓
Загружает Markdown-уроки
      ↓
Создаёт блоки и экзамены
      ↓
Выдаёт курс студенту
      ↓
        ↓
     Студент
        ↓
   Входит в аккаунт
        ↓
   Открывает курс
        ↓
   Проходит урок 1
        ↓
   Открывается урок 2
        ↓
   Проходит весь блок
        ↓
   Открывается экзамен
        ↓
   Сдаёт экзамен
        ↓
   Переходит к следующему блоку
        ↓
   Преподаватель видит весь прогресс
```
